# Arsip prototipe HTML

`login.html`, `register.html`, dan `js/` adalah referensi versi sebelum React.
Folder ini bukan entry Vite, tidak berada di `public/`, dan tidak disertakan dalam deployment.
Perbaikan fitur dilakukan pada `src/`; jangan memasukkan script DOM lama ke aplikasi React.
Aset CSS/gambar yang masih dipakai bersama tetap berada di `assets/`.
