# Mission Objective

Dengan mengerjakan mission dalam topik ReactJS ini, diharapkan Student bisa memahami konsep-konsep penting yang digunakan dalam library ReactJS dan bagaimana implementasi React dapat membantu mempercepat proses pembuatan UI sebuah website.

---

# Skill Set yang Diperoleh

* Mampu memahami konsep UI Component dalam React
* Mengimplementasikan konsep Reusable Component dengan memanfaatkan Props untuk passing data
* Mengimplementasikan UI yang responsif untuk berbagai ukuran device

---

# Case Brief

Sebagai Junior Developer di sebuah startup tech, Kamu diminta oleh user untuk menciptakan sebuah website statis berbasis React JS dengan tujuan melatih kemampuan dasar. Sebagai permulaan, kamu bisa membuat 3 halaman yang terdiri dari registrasi, login, dan homepage terlebih dahulu. Kamu bisa mengembangkan halaman lainnya jika merasa sudah nyaman dengan menggunakan ReactJS.

---

# Guideline & Instruction

Berikut merupakan guideline yang dapat digunakan untuk membantu dalam memulai project membangun website menggunakan library ReactJS:

1. **Slicing UI component pada masing-masing halaman login, register, dan juga homepage berdasarkan hierarki.**
   * **a.** Sebagai contoh di halaman register kamu bisa memisahkan UI menjadi komponen card pendaftaran akun yang di dalamnya memiliki komponen form nama, email, no HP, dan kata sandi. Kemudian kamu juga bisa membuat komponen button yang di dalamnya terdapat button daftar masuk, dan SSO.
   * **b.** Bagaimana kamu melakukan slicing dibebaskan sesuai kreativitas kamu, namun kamu boleh menggunakan guide atomic desain misalnya jika memudahkanmu melakukannya.

2. **Gunakan prinsip reusable component**, sehingga untuk memasukkan data pada setiap komponen kamu bisa melakukannya menggunakan props pada child component.

3. **Implementasikan Responsive menggunakan React.** Kamu bisa menggunakan CSS framework yang compatible dengan React seperti Bootstrap, Tailwind, Semantic UI, dll. Serta kamu bisa menerapkan react responsive library (`react-responsive`, `react-device-detect`, `react-media`).
